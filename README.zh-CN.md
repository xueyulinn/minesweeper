[English](README.md)

## 功能特性

- 经典扫雷玩法，提供初级、中级和专家三个难度等级。
- 使用 Tkinter 构建图形用户界面。
- 根据所选难度动态调整网格大小和地雷数量。
- 剩余格子计数器，用于跟踪游戏进度。
- 每局游戏开始时随机布置地雷。

## 安装

1. 克隆仓库：
    ```sh
    git clone https://github.com/xueyulinn/minesweeper
    cd minesweeper
    ```

2. 确保已安装 Python（版本 3.6 或更高）。

## 使用方法

1. 运行 `main.py` 文件启动游戏：
    ```sh
    python main.py
    ```

2. 点击对应按钮选择难度等级（Beginner、Intermediate、Expert）。

3. 开始游戏。

## 游戏玩法

- **目标**：在不触发地雷的情况下翻开所有非地雷格子。
- **操作**：
  - 左键点击格子以翻开它。
  - 右键点击格子以放置旗帜，标记疑似地雷。
- **胜利条件**：翻开所有非地雷格子即可获胜。
- **失败条件**：如果翻开的格子中包含地雷，游戏结束。

## 难度等级

1. **初级**：
   - 网格大小：9x9
   - 地雷数量：10

2. **中级**：
   - 网格大小：16x16
   - 地雷数量：40

3. **专家**：
   - 网格大小：24x24
   - 地雷数量：99
